# JavaScript Assignments

## Overview

This repository contains my completed JavaScript assignments written in Node.js. It includes solutions to **25 assignment questions** and **5 brain teasers** covering fundamental JavaScript concepts.

## Topics Covered

- Variables
- Data Types
- Functions
- Arrays
- JSON
- Comparison Operators
- Conditional Statements
- Loops
- Exception Handling

## Approach

Each question was solved using JavaScript fundamentals in Node.js. The solutions demonstrate the use of `console.log()` and `return` values as required by the assignment.

## How to Run

1. Clone this repository.
2. Open the folder in Visual Studio Code.
3. Open the terminal.
4. Run:

```bash
node assignment.js
```
